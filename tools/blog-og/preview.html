Blog Open Graph: define where title text may go

Internal canvas is always 1200 × 630 (same as generated PNGs). Load your template, then click and drag a rectangle over the area where the blog title is allowed. Download the JSON and merge textBox into tools/blog-og/config.json, or replace the whole file.

  1. Save your artwork as tools/blog-og/base.png (or load it here first to check composition).
  2. Draw the safe rectangle (green fill shows the allowed title region).
  3. Download config JSON → copy textBox into config.json.
  4. Run npm run og:blog from the repo root.
